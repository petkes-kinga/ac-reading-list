# Agatha Christie reading list

Interactive reading list for the works of Agatha Christie, focused on the Poirot and Miss Marple series. 

The content of the lists is highly based on the recommendations of the official Agatha Christie reading guides ([Agatha Christie official website](https://www.agathachristie.com/), UK edition) - but my personal notes and preferences may also influence the order and selection.

### Intended use

1. The markdown files can be loaded into any markdown reader or editor for interactive use. Suggested: Obsidian. Alternatively, progress can be tracked by forking the repository and updating the checkboxes in your fork.
2. Each file contains info about possible reading order constraints and a top 10 selection.
3. Each file contains a list with the full list of related works, with checkboxes (to track reading progress) and space for personal notes.
